# Devin Ecosystem — Linux

Native Linux execution with optional Devin VM/QwenPaw delegation when the selected tool supports it.

## Runtime

- local filesystem and Linux shell tooling;
- local execution of Devin Ecosystem tools;
- optional delegated scripts and workloads;
- optional additional compute;
- external integrations only when the registry declares them optional.

## Install

```bash
devin-devkit install <profile> --environment linux
```

See the [Linux guide](../../README.linux.md) and the [registry-generated compatibility matrix](../../COMPATIBILITY.md).
