# Devin Ecosystem — Personal Windows

Windows host execution with optional Devin VM/QwenPaw delegation when the selected tool supports it.

## Runtime

- local Windows execution;
- optional delegated scripts and workloads;
- optional additional compute;
- optional Linux-compatible delegated tooling;
- external integrations only when the registry declares them optional.

## Install

```powershell
devin-devkit install <profile> --environment personal-windows
```

See the [Personal Windows guide](../../README.windows.md) and the [registry-generated compatibility matrix](../../COMPATIBILITY.md).
